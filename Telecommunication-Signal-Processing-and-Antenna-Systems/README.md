# Telecommunication Signal Processing and Antenna Systems

## Overview

This repository contains a complete collection of telecommunication, radar signal processing, spectral analysis, antenna systems, and array-processing assignments completed as part of the **Telecommunication Project 2023** at **Hochschule Wismar University of Applied Sciences**.

The portfolio demonstrates practical work in digital signal processing, FFT-based spectral analysis, curve fitting, QAM signal simulation, coherent/incoherent integration, power spectral density estimation, antenna theory, antenna-array radiation patterns, Angle-of-Arrival estimation, and radar interferometry.

## Main Topics Covered

### 1. FFT and Window Function Analysis

Implemented frequency-domain analysis of sinusoidal signals using FFT and compared multiple window functions.

**Topics:**
- Time-domain and frequency-domain signal analysis
- FFT and spectral resolution
- Rectangular, Hann, Hamming, and Blackman windows
- Spectral leakage and side-lobe behavior

---

### 2. Curve Fitting and Residual Analysis

Applied nonlinear curve fitting techniques to synthetic datasets and analyzed residual behavior.

**Topics:**
- Sinusoidal fitting
- Exponential fitting
- Gaussian fitting
- Residual analysis
- SciPy curve fitting

---

### 3. Periodogram and Power Spectral Density Estimation

Implemented and compared different spectral estimation methods.

**Topics:**
- Standard periodogram
- Welch method
- Lomb-Scargle periodogram
- Power spectral density estimation
- Uniform and non-uniform time sampling

---

### 4. QAM Signal Simulation and SNR Analysis

Simulated complex communication signals and analyzed SNR improvements through integration techniques.

**Topics:**
- 4-state QAM signal generation
- Complex Gaussian noise
- Coherent Integration (CI)
- Incoherent Integration (NCI)
- SNR estimation and visualization

---

### 5. Antenna Systems and Wireless Propagation

Studied antenna types and their performance characteristics.

**Topics:**
- Dipole antennas
- Yagi-Uda antennas
- Patch antennas
- Parabolic antennas
- Antenna gain, bandwidth, impedance, and radiation pattern
- Beamforming concepts

---

### 6. Antenna Array Radiation Pattern Simulation

Simulated radiation patterns and array factors for square and equilateral antenna-array configurations.

**Topics:**
- 5×5 antenna arrays
- Wavelength spacing of 0.5 WL, 1.0 WL, and 1.5 WL
- Vertical and off-vertical beam pointing
- Radiation pattern visualization
- Array geometry and phase distribution

---

### 7. Angle-of-Arrival Estimation

Simulated AoA coverage using synthetic I/Q data and equilateral antenna arrays.

**Topics:**
- Synthetic complex I/Q signal generation
- I/Q diagrams and histograms
- AoA estimation
- Direction cosine plots
- Antenna spacing impact on AoA coverage

---

### 8. Final Radar Signal Processing and Interferometry Project

Processed atmospheric radar datasets from Saura and MAARSY radar systems.

**Topics:**
- Radar RAW data processing
- FFT-based Doppler spectral analysis
- Magnitude and phase spectrograms
- Coherent/Incoherent Integration
- Cross-spectral analysis
- Echo power estimation
- Angle-of-Arrival estimation
- Interferometric array simulations
- Circular, spiral, and random antenna-array coverage analysis
