# Project Summary

This GitHub project is a complete telecommunication and signal processing portfolio. It combines seven assignments and one final radar project covering core topics in Python-based digital signal processing, communication signal simulation, antenna arrays, beamforming, AoA estimation, and radar interferometry.

## Included Work

1. FFT and Window Function Analysis
2. Curve Fitting and Residual Analysis
3. Welch and Lomb-Scargle Periodograms
4. QAM Signal Simulation and SNR Analysis
5. Antenna Systems and Array Fundamentals
6. Antenna Array Radiation Pattern Simulation
7. AoA Estimation using Synthetic I/Q Data
8. Radar Signal Processing and Interferometric Array Analysis

## Professional Value

This repository demonstrates practical ability in scientific computing, mathematical modeling, signal processing, antenna-array analysis, and radar data analytics using Python.
